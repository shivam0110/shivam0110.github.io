# Shivam Malpani

Personal portfolio built with Astro and TypeScript.

```sh
npm ci
npm run dev
```

`npm run build` builds the site; `npm run preview` previews it.

Edit content and testimonials in `src/data/portfolio.ts`. Set `approved: true` once a testimonial is finalized. Replace `public/resume.pdf` to update the downloadable résumé.

Deploy from `main` to `shivam0110.github.io` with GitHub Pages set to **GitHub Actions**.
